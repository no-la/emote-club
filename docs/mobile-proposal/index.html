DESIGN DIRECTION 01

素材はすぐに。
編集は、親指の届くところへ。

提案：キャンバス固定＋下部パネル

最初に見えるのは、作っている絵文字とサーバーの共有素材。
下部の4タブで作業を切り替え、編集中も絵文字の見た目を追える構成を提案します。

「素材」を初期画面にする

素材一覧を開くためのひと手間をなくす。4列グリッドからタップでレイヤーに追加。文字の追加はヘッダーから1タップ。

触ったレイヤーを、その場で編集

キャンバスをタップして選択。文字・色と縁・字間と行間・大きさと不透明度をカテゴリで分け、長い設定画面を避ける。

重なりはレイヤー一覧で扱う

左端の44px幅のハンドルをドラッグして並べ替え。行本体のスワイプはスクロールに使い、上下ボタンも補助として残す。

完成後の行き先を「書き出す」に集約

PNG保存は512px、Discord登録は128px、素材共有もここから。登録先を確認してから追加し、Bot未参加時だけ導入を案内。

右のモックで試せます

  1. まるねこ素材を追加 → キャンバスで移動
  2. 「編集」で大きさ・不透明度を変更
  3. 「レイヤー」で ⋮⋮ をドラッグして順番を変更
  4. 「書き出す」から透過PNGを保存
  5. サーバーを「放課後クラブ」に切り替えてBot導入の表示を確認

類似サービスから取り入れること

MakeEmoji390px幅で操作確認

観察：アップロードとサンプル画像を上に置き、速度・方向・サイズなどをコンパクトな設定ボタンで選ぶ。プレビューを見ながら仕上げる流れ。設定を全部展開しない。

採用：画像を持っていなくても素材からすぐ試せる入口。細かい調整はカテゴリ別に開く。

絵文字スタジオ390px幅で操作確認

観察：単体作成は大きなモーダル。文字入力・3つの見た目の見本を先に見せ、フォントや装飾は「細かく調整」に畳む。32pxのチャット内プレビューを併置。

採用：実際の小ささでのプレビューを残す。文字の基本操作を先に出し、詳細は切り替えて使う。

Canva公式ヘルプ

確認：レイヤーパネルから対象を選択でき、長押し・ドラッグと挿入線で並べ替える操作を案内。

採用：キャンバスで選びづらい重なりは専用の一覧で選択。Emote Clubでは頻用を想定し「レイヤー」を最下部へ直接配置。

Canvaのモバイル実機・ログイン後エディタは未確認。下部4タブは本提案独自の構成で、Canvaの現行UIを再現したものではありません。

絵文字ジェネレーター390pxエミュレーション

観察：テキスト・フォント・色を横並びにするシンプルな構成。ただし今回のモバイル表示ではレイアウト幅が980pxとなり、画面全体が縮小された。

判断：PCの3カラムをそのまま縮小する方式は採用しない。画面幅に合わせて操作の構成を変える。

調査日：2026-10-18。ブラウザ確認はChromiumの390×844 CSS pxエミュレーション。実機Safari/Androidでは未検証。emoji.ggはセキュリティ確認画面で止まったため、モバイルUIの評価から除外。

この案のトレードオフ

PCのように素材・全レイヤー・全設定を同時には見られません。その代わり、キャンバスを残して1つの作業に十分なタップ領域を割り当てます。素材を大きく見たいときはパネル右上の ↕ で広げられます。

比較した別案：画面をまるごと「素材／編集」に分ける

素材は探しやすい反面、追加のたびに編集画面へ戻る必要があるため今回は見送り。素材数が増えたら、一覧だけを全画面表示する補助導線として追加できます。

モックでの確認結果

375×667・390×844・430×932で横方向のはみ出しなし。390×520の縮小表示で入力欄と「完了」が表示されることを確認。Chromiumのタッチイベントでレイヤー順を変更し、512×512の透過PNG保存も確認済みです。

実装時に詰める点

  • まず縦持ちスマートフォンを対象にする。PCの3カラムは維持。
  • キーボード表示時はキャンバスを小さくし、入力欄・「完了」を表示領域へ寄せる。モックはVisual Viewportに追従。
  • タッチの並べ替えはPointer Eventsを使い、移動用ハンドルだけスクロールを止める。端の自動スクロールも本実装で対応。
  • タップ領域は原則44px以上。色選択やパネル拡張など一部の補助操作は本実装で調整。
  • 元に戻す・やり直すを用意し、誤操作から戻れるようにする。モック内では操作可能。
  • 字間・行間・効果は本実装のPixiJS描画へ接続。このモックのCanvas 2Dは操作と見た目の検討用。

モックの素材・サーバーはダミーです。認証・DB・Discordには接続しません。PNG保存は動作します。モックにはピンチ操作、実際のフォント一覧、全体エフェクト、長いリストでのドラッグ端スクロールは未実装です。標準ブラウザズームは無効化していません。
